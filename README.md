# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 水位继承戳 | 切流同票落票：房间/切流世代/切前水位/锚点事件时/继承模式/戳号 |
| 热度窗 | 翻滚窗；开启累计，关闭发射；窗键带切流代次 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 / 切流拒收 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 末次撤回 |
| 入流闸 / 切流审计 | 开播闭播状态机的闸口与前后水位审计 |

## 开播闭播切流（已实现，全局唯一口径：重置水位）

- **重置（RESET）口径**：开播事务把水位**重置为开播事件时**；开播后第一条事件，事件时 ≥ 开播事件时则从重置水位向上推进；闭播只打状态、水位数值不动，但**关闭入流闸、关尽开启窗**，正式入窗一律失败闭拒收。
- 与「延续水位」口径的判别点：历史高水位下执行开播后读水位——本口径**降到开播事件时**（延续口径不降）。断言见 `backend/tests/test_切流.py` 夹具 A。
- **切流代次（epoch）**：每次开播/闭播 +1，写入窗键 `房|e代次|窗起`。新代次与历史窗分命名空间，已关闭历史窗在结构上不可被重开扫描。
- **失败闭并发**：开播/闭播/入流都在 `BEGIN IMMEDIATE` 临界区，同库同时刻仅一个写事务；抢锁失败转 HTTP 409，禁止切流半截、禁止双水位并存。
- 拒收的正式事件落命运「切流拒收」+ 旁路匣（原因 `切流拒收-*`），可经切流审计时间线追查。
- 接口：`POST /api/开播`、`POST /api/闭播`、`GET /api/切流态?房间键=`（房间、切流态、开播前后水位、valid）、`GET /api/切流审计`。
- 测试（纯 stdlib，无需 fastapi）：`cd backend && python3 -I tests/test_切流.py`。

## 水位继承戳（已实现，全局唯一取舍：继承戳锁模式）

- **同票写戳**：开播/闭播事务提交前同票写继承戳（房间、切流世代、切前水位、锚点事件时、继承模式、戳号）；戳写失败或收尾核证不过 → **整票回滚**。硬约束：禁止切流成功继承戳空。
- **锁模式口径**：戳写**重置**则水位从锚点事件时起算（本站稳态口径），戳写**延续**则保持切前水位；继承模式由当前世代戳锁定，直播间会话字段只是戳的投影——只改会话字段（如直改 `开播事件时`）不换世代，抬升写闸比对即识破，**抬升整票失败**。要改继承模式，唯一合法路径是重新开播/闭播：新开切流世代、同票重写戳（换票是锁模式的推论，不是第二套口径）。
- **落票自洽（切流写闸）**：切流事务收尾断言水位行符合已戳模式——戳声明重置则水位恰为锚点（禁止仍高于锚点事件时），戳声明延续/封存则水位恰为切前水位（禁止被静默改小）；违例整票回滚。
- **抬升吃戳（抬升写闸）**：开播后第一条抬升起，入流批次必须先吃本世代戳：戳缺失 / 会话字段与戳锚点不符 / 水位跌破已戳地板 → 整批抛错回滚（路由转 409 失败闭），不吞错、不暗写。
- **一脉一戳**：`(房间键, 切流世代)` 唯一索引，同世代双戳撞约束失败闭；水位行每房恰一行，切流写与抬升写抢锁由 BEGIN IMMEDIATE 串行化，不得并存两份水位行。
- **核证只读接口**：`GET /api/核证/水位继承[?房间键=]`——戳链、三硬约束核证（戳空/重置未落锚点/延续被改小）、以及与切流写闸、抬升写闸、入流拒写闸、热度窗页的协同快照（当前世代戳、闸口、开启窗世代、拒收数）；前端「水位继承核证」页直读，`GET /api/切流态` 与贯验亦带同套戳检查。
- 夹具见 `backend/tests/test_切流.py`：E 同票戳字段与核证、F 只改会话字段不换世代→抬升整票失败→换票恢复、G 戳写半截失败整票回滚。
